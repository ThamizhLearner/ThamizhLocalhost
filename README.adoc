= Thamizh Localhost

Locally hosted (_on your computer_) server application for Thamizh exploration.

== App preview

https://ThamizhConceptApp.OnRender.com

== Try it out (_on your computer_)

Ensure you have https://go.dev/dl/[go-lang] installed.

. Clone the repository +
`git clone https://github.com/ThamizhLearner/ThamizhLocalhost`

. Move into the newly created folder +
`cd ./ThamizhLocalhost`

. Start the server +
`go run .`

//
Follow the instructions as displayed::
. Open your web browser
. Enter `localhost:8080` in the address bar to access the local server
